# FinPilot Documentation

This directory is the compact entry point for implementation work. The full
product specification remains in
[`FinPilot_Master_Project_Context.md`](../FinPilot_Master_Project_Context.md).

Read only the documents required for the active task:

- [MVP scope](mvp-scope.md): product boundary and acceptance targets.
- [System architecture](architecture/system-overview.md): runtime boundaries,
  data flow, state ownership, and repository shape.
- [Quality gates](quality-gates.md): checks required before implementation and
  before declaring a phase complete.
- [Core architecture ADR](decisions/0001-core-architecture.md): accepted
  technology and responsibility decisions.
- [Module index](modules/README.md): links to module-specific context.
- [Repository Foundation](repository-foundation.md)

Module context is updated after material changes. Prefer links to source files
over copied code so later sessions can retrieve only the relevant context.
